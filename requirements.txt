# El backend usa el SDK de Google, no un POST a mano. La primera version de
# app/core/gemini.py eran ~40 lineas de urllib.request, con el argumento de que
# un SDK de 30 MB para hacer un POST con un JSON no se paga. Lo que paga el SDK
# no es el transporte: es `response_schema`. El esquema deja de ser texto dentro
# del prompt -una promesa que el modelo podia romper y que solo se descubria al
# parsear- y pasa a ser una garantia del servicio, lo que borro el parseo
# defensivo entero.
#
# La llamada a Gemini se mudo del frontend a aqui: alli la API key viajaba en
# el bundle de Vite y era publicamente extraible. Gemini sigue sin calcular
# nada: extrae y redacta; los numeros salen del motor determinista.
#
# Sin ORM y sin herramienta de migraciones: el DDL vive en Esquema.sql y se
# aplica con `python -m scripts.aplicar_esquema`. La base ya existe en el
# servidor; la app no la crea al arrancar
